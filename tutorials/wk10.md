## Practice questions
**Calculations:**
- 512-byte sectors, 4 KiB clusters → **8 sectors per cluster**.
- 4,096-byte sectors, 4 KiB clusters → **1 sector per cluster**.
- File 5,000 B, 4 KiB clusters, 512 B sectors → 2 clusters (8,192 B); slack 3,192 B. Last sector used: 5,000 − 4,096 = 904 B into cluster 2 → 904 B = 1 full sector (512) + 392 B into the 2nd sector → **RAM slack** = 512 − 392 = **120 B**; **drive slack** = remaining whole sectors = 8 − 2 = 6 sectors = **3,072 B**. Check: 120 + 3,072 = 3,192.
- Partition 41,943,040 sectors × 512 = **20 GiB**; starts at 2,048 → byte offset **1,048,576**.
- FAT32 entry size bytes `00 10 00 00` (little-endian) = 0x1000 = **4,096 B**.

**Short answers (one-liners to expand):**
- What is a ShellBag? Registry record of folder view settings in Explorer (NTUSER/UsrClass); shows folders were viewed, including deleted and removable ones; doesn't prove files inside were opened.
- What is a prefetch file? Windows' launch-speed record per program; run count, last run times, files loaded; may be disabled; absence ≠ never ran.
- What is an LNK file? Shortcut created when a file/folder is opened; target path, times, volume serial, drive type; copying without opening makes none.
- Why is FAT32 time awkward? Local time, no zone, 2-second resolution, access date only, no change time.
- What does Select\Current tell you? Which ControlSet is live, so you read the right time zone, USB and services data.
